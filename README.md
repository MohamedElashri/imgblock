# ImgBlock

This is a Firefox browser extension that removes all non-icon images from web pages with a single click. It have two simple buttons. One to remove all images and another to restore them. This is to help with reading some websites that have a lot of images that are not needed.


**Note:** I created this extension for personal reasons. I don't plan to extend it or add new features. If you have found any bug or problem then please open an issue on [GitHub](https://github.com/MohamedElashri/imgblock/issues). But will not accept feature requests. The goal is to keep this as simple as possible. If you really need a feature then feel free to fork the repository. 

## Installation

### Firefox
Download from [Firefox Add-ons](https://addons.mozilla.org) (Under Review)


### Manual Installation
1. Clone this repository
2. Open Firefox's extension page
3. Click "Load Temporary Add-on"
4. Select the `manifest.json` file


## Usage

Click the `ImgBlock` icon in the browser toolbar then you will get two buttons. One to remove all images and another to restore them. The restore button will be clickable only if we have removed images before.
